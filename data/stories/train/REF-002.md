# REF-002 — Partial refund for a multi-item order

**As a** customer
**I want to** refund only some items from my order
**So that** I can keep the items I'm happy with

## Acceptance criteria
1. On a Delivered order, the customer can select one or more items and a quantity for each item to refund.
2. Refund amount = unit price paid × quantity selected.
3. Items that are not selected are unaffected.
4. The order status changes to **Partially Refunded**. Once every item is refunded, it changes to **Refunded**.

## Example
Order #20311: 3 × T-shirt at €15.00 and 1 × Jacket at €120.00.
