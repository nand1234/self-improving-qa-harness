# REF-005 — Refunds for orders that used a promo code

**As a** customer
**I want** my refund to reflect the discount I received
**So that** the refund amount is fair and easy to understand

## Acceptance criteria
1. If an order used a promo code, the refund is based on the price the customer actually paid, not the list price.
2. Supported promo types: percentage (e.g. 20% off) and fixed amount (e.g. €10 off the order).
3. The refund confirmation shows the discount that was applied.

## Example
Order #50290: two items at €40.00 and €60.00, promo code SAVE10 (€10 off the order).
