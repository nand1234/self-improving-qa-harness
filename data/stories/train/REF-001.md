# REF-001 — Full refund within the return window

**As a** customer
**I want to** request a full refund for a delivered order
**So that** I get my money back when I'm not happy with my purchase

## Acceptance criteria
1. A customer can request a full refund for an order with status **Delivered** within 30 days of the delivery date.
2. Requests after the return window are rejected with the message "Return window has closed".
3. The refund is sent to the original payment method.
4. The customer receives a confirmation email showing the refund amount.
5. The order status changes to **Refunded**.

## Example
Order #10045, delivered on 2 June, total €89.90, paid by Visa.
