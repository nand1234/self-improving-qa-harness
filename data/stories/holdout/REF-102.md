# REF-102 — Bulk refunds by a support agent

**As a** support agent
**I want to** refund several orders in one action
**So that** I can handle incidents (e.g. a delayed shipment batch) quickly

## Acceptance criteria
1. A Support Agent can select between 1 and 50 orders and issue refunds in one action.
2. Ineligible orders (e.g. not delivered, outside the return window) are skipped, not refunded.
3. After the run, a summary shows how many refunds succeeded, were skipped or failed, with a reason for each skipped or failed order.
4. Individual refunds above €500.00 still go to Pending Approval.
